# TUDO — Bangladeshi Hearts. Real Connections.

A modern, responsive dating & matchmaking demo for Bangladeshi singles worldwide.
Static site (HTML/CSS/vanilla JS), demo data in the browser (localStorage).

## Run locally
Open a terminal in this folder and run:

    python3 -m http.server 8000

then visit http://localhost:8000
